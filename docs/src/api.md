# [API reference](@id api-reference)

The exported display functions are `clock`, `stopwatch`, and `countdown`.
The dial preference helpers are called with the `TerminalClock.` prefix.

## Displays

```@docs
clock
stopwatch
countdown
```

## Dial preferences

```@docs
TerminalClock.set_dials
TerminalClock.clear_dials
```
