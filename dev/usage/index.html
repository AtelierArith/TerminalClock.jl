Using the clocks

Terminal requirements

Use a terminal with ANSI cursor movement and a monospace font. The live displays erase and redraw lines in place. The bundled ASCII-style dials also use a Unicode colon symbol, so UTF-8 support is useful.

Give the default clock/countdown at least 79 columns and 9 rows; the default stopwatch uses 73 columns and 9 rows. A narrower terminal can wrap lines and leave stale output. Custom fonts may require different dimensions.

Run a single display at a time. Logging or printing from other tasks to the same terminal can disrupt cursor placement. Captured output in notebooks and CI logs may show escape sequences instead of an animation; use a single-frame method for those environments.

Clock

using TerminalClock
clock()

The clock displays the current local system time and refreshes about twice per second. It follows system clock changes. Use the stopwatch for measuring elapsed time.

A DateTime or Time argument produces a frame without waiting:

julia> using TerminalClock, Dates

julia> clock(DateTime(2026, 1, 2, 12, 34, 56)) == clock(Time(12, 34, 56))
true

julia> clock(Time(12, 34, 56, 789)) == clock(Time(12, 34, 56))
true

Stopwatch

stopwatch()       # Refresh every 0.01 seconds by default
stopwatch(0.05)   # Refresh every 0.05 seconds, reducing output work

The argument is a positive, finite floating-point number of seconds. It controls the refresh interval, not the total run time. Press Ctrl+C to stop; the live method returns nothing.

The display uses minute, second, and millisecond fields, MM:SS:mmm. The minute field wraps after 59: the display does not show hours. Its three millisecond digits do not imply a 1 ms screen refresh rate.

julia> using TerminalClock, Dates

julia> stopwatch(Time(1, 2, 3, 456)) == stopwatch(Time(0, 2, 3, 456))
true

See Timer accuracy for the distinction between elapsed time, frame timing, and the visible age of a frame.

Countdown

countdown()                      # Three minutes
countdown(minute=10)             # Ten minutes
countdown(second=5)              # Five seconds
countdown(hour=1, minute=30)     # One hour and thirty minutes
countdown(second=0)              # Display zero and return immediately

With no keywords the timer defaults to three minutes. Once any keyword is supplied, omitted components are zero. Components are validated by Dates.Time:

ComponentAllowed range
hour0–23
minute0–59
second0–59

For example, use countdown(hour=1) for one hour; countdown(minute=60) is invalid. The API represents durations shorter than 24 hours.

You can also supply a Time, interpreted as a duration since midnight:

using Dates
countdown(Time(0, 10))
countdown(Time(0, 0, 0, 500))     # Half a second

The display rounds remaining seconds up. A half-second timer initially displays one second, then zero. The function returns nothing after the zero frame, without sleeping for another second. Ctrl+C ends the timer early.

SymptomWhat to check
Rows drift or overlapIncrease terminal width/height; stop other output to the same terminal.
Cursor codes appear in a logRender a single frame with clock(t) or stopwatch(t).
Digits update in burstsReduce terminal load; a shorter interval cannot prevent OS or terminal stalls.
